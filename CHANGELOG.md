# Changelog

## [1.6.0-1] - 2026-05-07

### 🔄 Архитектура и Сборка
- **Обновление upstream:** Исходный код обновлен до версии **1.6.0** (извлечен из официального AppImage).
- **Portable сборка:** Добавлен `native-build/build.sh` для создания портабельного `.run` инсталлятора на базе AppImage.

### ⚡ Приложение
- **Electron runtime:** Целевая версия Electron остается **38.2.0**.
- **ToDesktop framework:** Обновлен до `desktopifyVersion: 6.29.0`, `desktopifyServerVersion: 1.613.1`.
- **AppImage формат:** В upstream перешли на упаковку приложения в `app.asar` (ранее файлы были распакованы).

### 📦 AUR Пакет
- **PKGBUILD:** Версия обновлена до `1.6.0`, `pkgrel=1`.
- **.SRCINFO:** Перегенерировано.

## [1.4.0-2] - 2025-11-28

### 🔄 Архитектура и Сборка
- **Переход на Native:** Полный отказ от использования бинарных сборок `deploy_aur`. Теперь пакет собирается исключительно из исходного кода.
- **Очистка зависимостей:** Удалены устаревшие bundled-библиотеки (`usr/lib/`) из репозитория. Пакет теперь использует системные библиотеки Arch Linux (`electron`, `libnotify`, `libappindicator-gtk3`).
- **CI/CD:** Обновлен GitHub Actions workflow для сборки Native-пакета с использованием актуального хеша коммита.

### ⚡ Приложение
- **Обновление ядра:** Исходный код обновлен до версии **1.4.0** (Electron 38 compatible codebase).
- **Исправление UX:** Включена опция `"autoHideMenuBar": true` в `todesktop.json`. Верхнее меню теперь скрыто по умолчанию и появляется при нажатии `Alt`.
- **Имя пакета:** Исправлено имя в `package.json` на lowercase (`perplexity`) для соответствия стандартам npm/linux.
- **Лицензия:** Явно установлена лицензия `Apache-2.0` в `package.json`.

### 📦 AUR Пакет
- **PKGBUILD:**
  - Обновлена версия до `1.4.0`.
  - Исправлены контрольные суммы (`sha256sums`) для всех файлов.
  - Убрана логика копирования `vendor-libs`, так как они больше не нужны.
  - Добавлен fallback на `git+https` для исходников.
- **Launcher:** Убрана модификация `LD_LIBRARY_PATH`, скрипт упрощен для работы с системным окружением.

### 📚 Документация
- **README:** 
  - Актуализирована информация о версиях (System Electron / Target Electron 38.1.0).
  - Убраны некорректные бейджи загрузок (GitHub Downloads), так как пакет собирается из source.
  - Удалены устаревшие разделы про бинарную сборку.
- **Architecture:** Документация приведена в соответствие с единым Native-пайплайном.

### 🗑️ Очистка
- Удалены рудиментарные файлы: старые архивы `tar.gz`, папка `deploy_aur`, временные файлы `AppImage`.
- Обновлен `.gitignore` для предотвращения попадания артефактов сборки (`pkg/`, `src/`, `*.pkg.tar.zst`) в репозиторий.
